# 山海行笺使用手册

核对日期：2026-09-18。本文描述当前界面和代码行为；实际验证结果及尚未完成的真实服务联调见 [验证记录](VERIFICATION.md)。部署与环境变量见 [开发指南](DEV.md)。

## 1. 开始一份旅行

山海行笺通过文字、景点照片、菜单和攻略截图帮助你规划旅行。每份「行笺」是独立工作区，包含当前行程、历史版本、多段对话和旅行偏好。一个工作区内的不同对话共同编辑同一份行程；另一趟旅行应新建行笺。

1. 注册或登录。普通用户进入工作台，管理员进入后台后也可返回工作台。
2. 点击左栏「新建行笺」，或在空白工作台写下需求。填写目的地、天数、人数、预算和节奏的引导表单会先把需求填入输入框。
3. 选择「联网搜索」和「思考深度」，再发送文字或图片。
4. 检查生成的摘要、每日安排、景点与美食图片、城市地图。可继续追问或使用可视化表单调整。
5. 保存后刷新，行程、已提交聊天与图片附件可恢复。

示例需求：

> 为两位成人安排杭州三日游，预算 3000 元，不含往返大交通。喜欢园林、老街和小吃，节奏舒缓，每天最多三个主要景点。请加入美食手账和预约清单；无法确认的信息标为待核实。

Enter 发送，Shift + Enter 换行。仅出现建议文字不表示行程已经修改；以成功的编辑工具结果、预览及当前规划为准。没有 AI 配置时仍能手工维护行程。

## 2. 联网、思考和图片

| 选项 | 行为 |
| --- | --- |
| 联网搜索 | 独立开关。关闭时不会调用搜索工具。启用后由模型按需调用，界面保留实际返回的标题、链接、摘要和获取时间 |
| 搜索提供方 | 支持 DeepSeek 官方搜索或 Tavily 独立工具；显示实际提供方，无可用配置时禁用开关 |
| 思考深度 | 关闭／轻量／标准／深度。按当前模型实际支持的参数映射，不支持的档位禁用 |
| 默认选择 | 按账号保存到服务器；每轮请求单独保存当时的配置，改默认值不会改变历史请求 |
| 模型能力 | 输入框显示当前模型以及是否支持图片；不能识图的模型不会静默忽略附件 |

点击「添加图片」，也可拖拽或粘贴图片到输入框。每轮最多 4 张，单张不超过 5 MiB；支持静态 JPEG、PNG、WebP。服务器会真实解码并校验尺寸：单边最多 8192 像素，总像素最多 2400 万。上传显示预览和进度，失败可重试，发送前可移除。图片全部上传完成后，既可单独发送，也可配文字。

可尝试：

- 「根据这张景点照片规划周边两天旅行，认不准地点时先说明。」
- 「读取菜单，推荐适合两人且不吃辣的菜，并加入食记。」
- 「根据这张攻略截图调整第二天，保留已经确定的住宿。」

图片先通过独立接口上传，聊天只提交附件引用。已发送图片随消息保存，刷新后可查看，也会作为同工作区后续追问的图片上下文；长历史受模型上下文预算限制，不保证无限图片记忆。图片识别有不确定性，涉及行程修改仍需通过校验后的结构化工具。

未发送的输入和附件队列不等同于已保存历史。未关联消息的服务器附件超过 24 小时会清理；已发送附件随其引用的会话保留。请勿把浏览器草稿当作跨设备备份。

## 3. 图文结果与地图

最新行程预览包含摘要、每日地点、食记和图文结果。点击「打开图文行程与地图」进入完整规划。行程文字先可使用，图片与地点资料分批补齐；资源变化不会为每张图增加行程版本。

- 景点图片标为「地点实拍」；食记图片标为「菜品示意」，不会冒充指定餐厅实拍。
- 图片保留来源页面、提供方和署名。只展示实际取得并匹配的图片；找不到时保留说明。
- 图片按可见区域加载并使用缓存。查找失败可点「重试图片与定位」，图片加载失败也可单独重试。
- 城市地图可切换目的地城市和每日路线。总览展示地点分布，每日连线表示游览顺序。
- 单张地图最多显示前 10 处地点；路线舆图可按页查看和编辑更多地点。连线不是道路导航，不提供道路行驶距离或预计用时。

在线地点查询按城市、名称和地址消歧，坐标由服务端取得，采用 BD-09。无法确认的地点保持待定位，文字安排仍可编辑；你也可以手工填写成对的可靠 BD-09 经度、纬度。地图和街景需要部署者配置百度服务端 AK；无配置、权限不足或暂无影像时会显示失败说明。前端不会接收地图密钥。

历史预览保留其版本内容；不会把新版本的图片关联到已修改的历史地点。切换到相应版本后，可为当前行程重新取得资源。

## 4. 工作区与五个页签

左栏支持行笺展开、搜索、按创建／更新时间排序，以及工作区和会话的分页加载。窄屏下侧栏是抽屉，Escape 可以关闭。设置入口位于账号区域。

| 入口 | 可操作内容 |
| --- | --- |
| 行程总览 | 摘要、每日安排、图鉴、城市地图、预算、旅行提示、清单与版本历史 |
| 编辑资料 | 名称、简介、封面链接、标签、预算明细、提示及 Markdown 旅行手记 |
| 路线舆图 | 新增／编辑每日安排，添加／编辑／删除／移动景点，查看静态地图 |
| 风物食记 | 菜名、餐厅、城市、日期、餐次、想吃／已尝、花费、评分、笔记与图片 |
| 沿途街景 | 已定位地点的静态街景，可调整方向与视野；不是实时视频或连续导航 |
| 旅行偏好 | 当前行笺的偏好，或账号全局偏好，供后续生成使用 |
| 对话中的版本路线 | 查看版本分支、加载更多历史并切换版本 |

标签用逗号或顿号分隔，行前提示每行一条。预算总额、预算明细、景点花费和美食花费分别保存，不自动换汇或保证合计一致。封面仍通过链接设置；聊天上传的照片作为消息附件，不自动替换封面。

行程最多 90 天、每天 50 个地点；食记最多 300 条，清单最多 100 项。新增／编辑／移动等操作保存成功后才更新服务器。菜品评分为 0～5 的整数，0 表示未评分。

删除会话会删除其聊天记录；删除行笺会删除其版本、对话等关联数据。界面没有回收站，版本切换不能恢复已删除的工作区。当前没有多人邀请、票务支付、酒店预订、PDF／Word 导出或完整账号导出入口。

## 5. 保存、草稿、冲突与版本

AI 工具成功编辑时已提交行程。聊天底部「保存行笺」保存当前规划，相同内容不重复创建手工版本；表单草稿应通过对应表单保存。

地点、食记、规划资料与旅行偏好草稿按账号、工作区和对象存于本机。刷新或切换工作区后可恢复。服务器报告 409 冲突时，草稿保留：先「比较最新内容」，再明确「重新应用」并检查后保存。离线规划快照为只读，恢复联网后刷新再保存。

版本号可以回退，独立的 revision 用于判断是否基于过期内容。切换 v3 到 v1 不增加新版本；随后修改会产生以 v1 为父版本的新分支，原版本不删除。同一轮 AI 在其版本仍为当前版本时继续更新该轮版本；切换指针或换轮后再追加。

| 内容 | 切换行程版本 |
| --- | --- |
| 标题、摘要、封面、标签、预算、提示 | 恢复目标版本的值 |
| 每日行程、地点、交通、住宿、美食、清单 | 一起恢复 |
| 独立 Markdown 旅行手记、全局／行笺偏好 | 不随行程版本回退 |
| 聊天与图片附件 | 保留已有消息；符合会话关联时追加版本操作说明 |
| 图片与地点资源状态 | 按当前实体和修订重新关联，不制造额外行程版本 |

版本与消息首批默认加载 50 条，可用「更多历史版本」「查看更早的对话」继续翻页，不会因为首屏看不到就删除旧记录。预览的差异明细最多展开 12 项；「复制 JSON」取得该版本完整结构化行程，但不包含完整账号、聊天与偏好备份。

## 6. 生成中断与重试

同一行笺查看预览或设置不会停止生成。切到其他工作区或会话会停止当前生成，也可主动点击停止按钮。已提交的工具修改不会因取消而自动撤销。

中断、失败或服务重启后，点击「查看已保存结果」恢复数据库中已提交的行程、预览和消息检查点。尚未保存的 token 不承诺恢复。失败后可以重新编辑需求；「作为新一轮重试」会创建新请求，可能再次执行修改，所以先核对已有结果。

界面仅显示实际处理状态和真实返回来源，不把等待时间、长回答或动画当作思考深度。搜索没有执行或失败时不会宣称成功。

## 7. 偏好、管理员与部署

旅行偏好可写节奏、预算、忌口、语言风格和称呼等。优先采用有内容的行笺偏好，其次全局偏好，最后系统默认；不会自动合并两份偏好。因此本次旅行仍需遵守的全局要求，应写入行笺偏好。偏好限制 4000 字符，支持界面提示的变量；其版本用于冲突判断。

管理员可查看统计、管理用户与规划、清理后端缓存。角色以服务端为准；前端导航不是权限边界。清理后端缓存不会同时清空每台设备的 IndexedDB。AI、搜索和地图密钥由部署者在服务器环境变量中配置，后台不提供密钥输入页面。

已有数据库请先一致性备份，使用 Drizzle 迁移升级，不覆盖原库。启动、迁移、隔离验收及备份命令见 [开发指南](DEV.md)；品牌原稿与导出规格见 [品牌文档](BRAND.md)。

## 8. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 联网开关灰色 | 部署者检查官方 DeepSeek 密钥、API 地址和 AI_SEARCH_PROVIDER，或配置 Tavily；更新后重启应用并刷新页面。不开联网也可生成，景点美食图片独立获取 |
| 思考某档不可选 | 当前模型没有对应能力，不能靠提示词伪装支持 |
| 无法添加图片 | 查看当前模型是否支持视觉，再检查格式、大小和图片尺寸 |
| 上传失败 | 图片草稿保留，点击重试；达到额度时移除未发送附件或不再需要的工作区 |
| 图片已上传但不能发 | 等全部图片完成；失败的图片重试或移除 |
| 景点没有照片或定位 | 查看真实失败原因、来源服务配置或消歧信息；可以重试，不会补假图假坐标 |
| 地图空白 | 检查可信坐标及百度配置；静态图失败不影响文字行程 |
| 409 版本冲突 | 保留草稿，比较最新内容后重新应用 |
| 429 或任务排队 | 等待配额／并发恢复，不连续重复提交 |
| 刷新后少了生成中的内容 | 只恢复已经保存的消息与检查点，查看当前行程和版本 |
| 搜索不到旧行程／会话 | 确认账号、部署实例和搜索条件，继续加载更多页面 |
| 401／403 | 重新登录或核对权限；权限错误不会退回旧缓存冒充可访问 |
